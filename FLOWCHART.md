## Module Groups & Connections

### 🎵 MUSIC (Create Your Art)
```
┌─────────────────────────────────────────────────────────┐
│                                                         │
│  Releases ──────► Distribution ──────► YouTube          │
│  (Timeline)      (DSP Status)        (Content ID)       │
│      │               │                    │             │
│      ▼               ▼                    ▼             │
│  Publishing ◄──── Metadata         Monetization         │
│  (Songs)        (ISRC/ISWC)        (Ad Revenue)        │
│      │               │                                  │
│      ▼               ▼                                  │
│  Royalties ◄──── Collection                             │
│  (7+ streams)   Agencies                                │
│                                                         │
└─────────────────────────────────────────────────────────┘

How money flows:
  Song → PRO → Performance Royalties
  Song → MLC → Streaming Mechanicals
  Song → HFA → Physical Mechanicals
  Recording → Distributor → Streaming Revenue
  Recording → SoundExchange → Non-Interactive Digital
  Recording → YouTube CMS → Content ID Revenue
```
